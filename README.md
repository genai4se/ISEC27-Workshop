# GenAI&SE @ ISEC'27 — Workshop Website

Official website for the **Fourth Workshop on Generative AI & Software Engineering: Co-Pilots to Actors**, co-located with [ISEC'27](https://conf.researchr.org/home/isec-2027) at SPIT Mumbai, India on **February 18, 2027**.

## About the Workshop

The workshop explores the evolution of Generative AI from coding co-pilots toward autonomous AI actors that can plan, decide, and act inside software systems. Topics span Agentic AI, multi-agent systems, AgentOps, software architecture, legacy modernization, trust, security, and human-AI collaboration.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool, dev server on port 8080)
- **Tailwind CSS** + **shadcn/ui** (Radix UI primitives)
- **React Router v6**
- **TanStack Query**
- **Supabase** (integration)
